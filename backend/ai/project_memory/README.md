# AI 项目规则说明

这个目录用来存放 AI 1.0 的“业务规则记忆”。

这里不是聊天记录，也不是运行时缓存。它的作用是把 AI 后续要遵守的规则写进仓库里，这样你在 WSL 里开发后，通过 `tb-package` 迁移到服务器时，这些规则会跟着代码一起迁移。

## 当前包含什么

- `task_ticket_rules.md`：AI 创建 TB 任务单时要遵守的字段和判断规则。
- `task_analysis_rules.md`：AI 做任务分析时要看哪些数据、怎么输出结论。
- `data_contracts.md`：AI 1.0 计划使用的接口入参和返回结构。

## 1.0 原则

- 这里保存“规则”，不保存用户每一轮聊天内容。
- 用户临时对话、ttyd 工作区、页面草稿都属于运行时状态。
- 运行时状态可以丢，规则不能丢。
- 后续如果某条业务规则需要迁移到服务器，就应该写到这个目录里，或者落到数据库里。

## 迁移边界

`backend/runtime/` 会在打包时被清理，所以不要把长期规则只放在 runtime 里。

真正需要长期保留的 AI 规则，目前都应该放在这个目录下。
