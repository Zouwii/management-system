# tb_tool_b1 前端（独立版）

这是把 `backend/static/index.html` 分离出来的独立前端页面。

## 运行方式

### 1）先启动后端

后端默认端口是 `5001`，保持不变即可。

### 2）启动一个静态服务器（前端）

在 WSL/Linux 下：

```bash
cd /home/zhr/zhr_ws/src/tb_tool_b1/frontend
python3 -m http.server 5173 --bind 0.0.0.0
```

然后浏览器打开：

- `http://127.0.0.1:5173/`

页面顶部“后端地址”默认是 `http://127.0.0.1:5001`，如果你后端跑在别的机器/IP/端口，改掉并点“保存”即可（会写入浏览器本地缓存）。

## 同事访问你的前端（局域网）

让同事访问你的机器 IP：

- `http://你的IP:5173/`

并把页面顶部“后端地址”改成：

- `http://你的IP:5001`

> 需要你在 Windows 防火墙放行 `5173`（前端静态服务器）和 `5001`（后端）。
