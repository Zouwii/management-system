## 口径说明

1. **本体开发部**：5,811 = token 1 + 任务列表 340 + 任务明细 5,470。
2. **算法组**：1,448 = 任务列表 36 + 算法开发明细 575 + 算法问题明细 837；token 刷新时可再增加约 1 次。
3. **现场问题单**：下限由列表、任务明细、动态/评论和附件元数据组成。B 表请求经 Teambition 代理发出，尚未进入 `api_call_logs`，实际用量可能更高。
4. **核心知识库全量拉取**：6,154 只包含目录和文档元数据同步到 DB，不包含 Markdown 正文下载。
5. **未入库正文下载**：当前 `kb_documents` 共 6,717 条，已入库 6 条，待下载 6,711 条。6,711 是 MCP 请求数，不是已实测的底层钉钉 API 总数；入库后未变更文档不再重复下载。

> 以上 5 组业务均为独立触发口径，不建议直接相加作为日常用量。
