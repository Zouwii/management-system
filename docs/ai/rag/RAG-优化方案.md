## 2. 优化路线

### Phase 1: 补短板（低成本高收益）

| 项 | 方案 | 预估提升 |
|----|------|---------|
| **加 Reranker** | BGE-reranker-v2-m3 | NDCG@5 +34% |
| **建立测试集** | TREC Pooling + LLM 标注 | 量化评测基础 |
| **保真度修复** | 图片占位符 + block 元数据保存 | 减少信息丢失 |

### Phase 2: 换模型（中等成本）

| 项 | 方案 | 预估提升 |
|----|------|---------|
| **升级 Embedding** | bge-large-zh-v1.5 → bge-m3 | NDCG@5 +10-15% |
| **重构分块** | 层级分块 + 小大块策略 | 语义完整性 |
| **元数据注入** | heading/path/source 融入 chunk | 上下文增强 |

### Phase 3: 架构升级（高成本高收益）

| 项 | 方案 | 预估提升 |
|----|------|---------|
| **Query 改写** | LLM 扩展/分解用户问题 | 复杂问题命中率 |
| **HyDE** | 假设文档嵌入 | 语义桥接 |
| **多路召回** | 关键词 + 向量 + 知识图谱 | 覆盖盲区 |
| **自适应检索** | 按问题类型动态选策略 | 精准匹配 |

## 3. 已确认有效的方案

### 3.1 Reranker

对照试验证明 **BGE-reranker-v2-m3** 是最大单点提升：

- 在 top-20 候选上重排 → top-5
- NDCG@5 从 0.47 → 0.63 (+34%)
- 不影响召回环节，纯后处理

### 3.2 分块策略

4策略自适应分块已验证有效：

| 文档类型 | 策略 | 粒度 |
|---------|------|------|
| 技术文档（有 `##` 层级） | 层级分块 | 800-1000 token |
| 会议纪要/周报 | 段落聚合 | 500-800 token |
| 表格（.axls） | 行分组 + 表头前缀 | 20-30 行/片 |
| 其他 | 固定窗口 | 800 token，150 重叠 |

每个切片注入元数据：文档路径 + 章节标题 + 知识库来源。

### 3.3 bge-m3 评估

bge-m3 (1024d, dense+sparse 合一) 单独替换提升有限 (~+10%)，但结合 reranker 后效果更优。建议在 bge-large 稳定运行后再迁移。

## 4. 嵌入模型选型

| 模型 | 维度 | 大小 | 中文 | 适合 |
|------|------|------|------|------|
| bge-small-zh-v1.5 | 512d | ~100MB | 一般 | 快速原型 |
| bge-large-zh-v1.5 | 1024d | ~1.3GB | 好 | **推荐基线** |
| bge-m3 | 1024d | ~2.2GB | 最优 | dense+sparse 合一 |
| text-embedding-3-small | 1536d | API | 好 | 无需 GPU |
