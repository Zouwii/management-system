2. 转向指令\+转向角度，转向前“需求车速”需提前下降。

5. 前进或后退\+需求车速：正常行车状态
6. 大灯亮指令:大灯点亮。<span style="color: #FF0000;">协议内容 夜间自动开灯。</span>
7. 到站停止即为到点刹车，逻辑为到目标点先刹车车速为0后驻车。
