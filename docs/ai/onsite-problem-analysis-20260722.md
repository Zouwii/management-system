## 3. 可检测的重复问题模式

### 3.1 行为树报错（12条，6.8%）

**典型描述**：
- "请保证起步时，距离目标点的距离大于设定的异步起始距离"
- "行为树报错，库位路径收到非法导航任务"
- "行为树放货动作报错"

**根因**：nav-manager 获取到历史距离、算子未合入最新优化、两次调度任务一致但未过滤

**可检测特征**：`行为树` + `报错` / `异常`

### 3.2 定位漂移/不可控（18条，10.2%）

**典型描述**：
- "到点和调度任务无法移动"
- "伺服时报错库位路径收到非法导航任务"
- "在位姿初始化附近，小车明显出现了漂移"

**根因**：nav-manager 更新地图锁机制缺失、costmap 分辨率过低、角度误差累积

**可检测特征**：`定位` / `位姿` / `漂移` / `偏移` / `到点不动`

### 3.3 调度通信异常（12条，6.8%）

**典型描述**：
- "执行卸货动作后不结束任务，调度信号也清了"
- "交管后导航无法移动，本体无报错"
- "调度执行搬货任务伺服前先报错"

**可检测特征**：`调度` + `不动` / `无法` / `信号`

### 3.4 交管异常（8条，4.5%）

**可检测特征**：`交管` + `异常` / `无法`

### 3.5 控制震荡（2条）

**典型描述**：
- "导航控制指令发生震荡，然后进库位在库位里面搬货原地旋转"

**可检测特征**：`震荡` / `振荡`

### 3.6 碰撞（7条，4.0%）

**典型描述**：
- "取料撞料箱导致料箱掉落"
- "小车撞风淋门"

**可检测特征**：`撞`

## 5. AI 可介入点

| 能力 | 说明 |
|------|------|
| **自动分类** | 描述中有关键词（行为树/定位/调度/碰撞）→ 自动归入对应子类型 |
| **版本关联** | 识别软件版本号，匹配历史同类问题及解决方案 |
| **重复检测** | 同一关键词 3+ 次出现 → 标记为"高频问题"，建议标准化处理 |
| **方案推荐** | 历史同类问题解决方案中有 30 条都是"更新版本" → 推荐先查版本 |
| **关闭单审计** | 14 条"未复现关闭" → AI 可追问是否有日志留存、现场环境是否变化 |

## 6. 建议

1. **行为树报错** 和 **定位漂移** 是最高频的两类问题，可建立标准化排查流程
2. **2.2412 版本** 集中了 44% 的本体导航问题，该版本 release 后应重点关注
3. **EMMA K系列** 车型问题密度最高，是否涉及特定硬件/固件组合值得排查
4. **"未复现关闭"** 的单子可要求必须附日志/截图，避免信息丢失
