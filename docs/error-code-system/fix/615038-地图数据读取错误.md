# 615038 地图数据读取错误

## jstate
`error/nav-net/get_map_data_failed`

## 错误解释
在定位自恢复过程中，需要读取地图一些参数，读取失败会报警告。

## 等级
level5（错误）

## 常见原因
1. `/map_master/get_current_map_info` 服务调用失败
2. 地图文件损坏或格式异常
3. map_info 中缺少 edges/nodes 数据
4. nav-net 与 map_master 通信异常

## 排查思路

### 1. 查看 nav-net 日志
日志文件: nav-net.log  
关键字: `get map info from /map_master`

```
get map info from /map_master/get_current_map_info failed
```

若出现此日志，说明服务调用本身失败。

### 2. 手动调用服务验证
```bash
rosservice call /map_master/get_current_map_info "data: '[\"map_png_info\"]'"
```
- 接口有返回错误 → 联系地图相关维护人员
- 接口返回正确 → 联系 nav-net 维护人员

### 3. 检查 map_info JSON
确保返回的 JSON 中包含 `edges` 和 `nodes` 字段。
